# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程（v8，以「落位色块」版为基础）

1. **绽放**（约 2.4 秒）：暗场，微尘飘向镜头。标志从中心长出：每一块都从标志中心点放大到位（中心方块带回弹，随后两对角件成对，最后两片红刃），整枚标志从屏幕深处轻轻前移。暗场中深蓝部分显示为纸白。
2. **蓄力**：在画面上**按住**鼠标（或空格 / 回车），标志缩小 14%、反向转 28°，红刃收紧、中心方块微缩，约 0.45 秒蓄满；**松开**即弹开。快速单击也会先蓄到 60% 再放开，保证能看到这一下。滚轮、上滑、↓ 会自动做一段 0.22 秒的短蓄力。绽放过程中也可以触发。
3. **开幕**（约 2.15 秒，边转边开）：从蓄力的反向角度开始转到 180°，用 outCubic，**松手瞬间转速最快**，随后减速，与碎片落地同时停下（0–2.1s）。同时标志先弹回原大小（0–0.3s）再放大（0.1–1.1s），碎片以 outQuint 落到四角（0.6–2.1s）：左上、右下深蓝块，右上、左下红刃尖角。快落地时才由纸白变深蓝（0.9–1.55s），暗场同时淡出（0.94–1.62s），首页内容从 1.15s 起浮现。色块留在首页首屏，随页面滚走。

首屏：纸色底，左边装框的油画，右边 TEISU 字标、一句话、小字，没有入口卡片。

时间点在 `T`（`lit` 是变色、`bg` 是暗场淡出）、`BLOOM`、`INTRO_END`；旋转角度 `SPIN`（必须是 180 的倍数）；蓄力角度与缩小量在 `WIND`、`charge()`，最短蓄力 `MIN_WIND`；落位位置在 `FINAL` / `FINAL_NARROW`（参数含义同正式站点 gate.ts）。旧的 v4 原型保留在 `template-v4.html`（`node lab/opening/build.mjs template-v4.html`）。
