# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程（v4）

1. **A 法阵**（滚动驱动，约 900px 滚动量到 100%）：红色只在中心，核心从水平的「红 ▪ 白 ▪ 红」随进度扭成斜刃。外面一圈圈白色臂：**走向有序**——同心、只走横竖、每圈左上/右下与右上/左下 180° 对称（和标志一致）；**形状凌乱**——起止位置、长短、内勾长度各不相同，线会断成 1–3 截，拐角有时 45° 斜切，沿途有时出现一个 45° 小错位（电路走线），粗细略有差异，越往外越粗。所有臂一开始就在，只是很短，长度随进度各自伸长。进度 30 / 60 / 90% 时各圈按 90° 的整数倍转动，100% 时全部对齐。停手会慢慢退回；点击或回车自动补满。
2. **B 开幕**（自动，约 3.9 秒）：最内圈落定为精确标志 → 镜头拉远 6 倍（不旋转）→ 45° 斜边从左侧扫过，线条先染色 → 第二道斜边把缝隙填成首页 → 淡出到首页首屏。

形状随机度在 `hookArm()`、`elbowArm()`、`dashes()`；圈距、线宽在 `buildRings()`（种子 `seed = 11`，改种子可换一套形状）；时间点在 `TB`、`CLICKS`；拉远倍数 `ZOOM`；斜边在 `sweep()`。
