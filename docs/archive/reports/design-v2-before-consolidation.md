# design.md — v2 视觉与空间交互

版本：2.0 · 2026-10-25

## 1. 稳定的艺术方向

用真实研究对象建立视觉识别。字体、图片和留白主导页面；互动丰富，静止构图清楚；项目详情适合阅读。

用户最喜欢 Lusion 的艺术气质、交互感与克制感，具体关注鼠标轨迹、标题响应、封面的跟焦与视角跟随。本文为单张项目图制定自己的实现合同，不声称这是 Lusion 的内部技术。

“日系克制感”不自动等于米黄、纸纹、竖排或某种字体。正式站名、品牌色、署名和项目事实没有依据时不补造。

## 2. 展示区域围绕对象组织

先判断原图中最能代表项目的可见对象，再建立标题、主体、说明与空间的关系。照片中心不一定是观察锚点。

对于本轮 GNSS-R 站点，原图若与截图一致，应重点检查板卡与接口是否足够突出、近处盒盖是否占据过多注意力、摄影背景是否形成未经组织的大块底板。具体裁切与分层必须看原图决定。

可以保留场景，也可以可靠分离对象：

- 能分离时，让主体、必要前景与背景形成完整空间关系，保留细线、接口、外壳和真实细节。
- 不适合分离时，保留环境，通过主体尺度、裁切和外围明暗关系统一展示区域。
- 完整实物记录照片可放详情页；主页允许更集中的裁切，不生成未知结构。
- 不强制消灭一切矩形边界；需要消除的是随意贴图感。

静止时主体与标题应足以构成首屏。不要靠入场动画、漂浮符号和持续发光填补构图。

## 3. 配色与排版

颜色由原图与可读性共同决定。图片背景、CSS 背景及 WebGL 背景使用同一颜色配置；正确处理颜色空间，避免 Canvas 启用后变灰或跳色。

本轮一个默认配色、一个主要强调色。背景色不必与整张照片的平均色相同；可以从外围环境选取再调整，但不改变具有含义的元件与线缆颜色。

文字以无衬线为默认，中文有完整回退。正文与必要元信息目标对比度至少 4.5:1。用尺度与位置建立层级，避免到处加粗、过细浅灰字、无功能英文和成排徽章。

可调初值：桌面主标题约 64–112 px，手机约 36–56 px，正文 16–18 px、行距 1.65–1.85；正文宽度约 34–40 rem。以实际画面为准，不机械守住数字。

## 4. M01 — 视角跟随是主要趣味

在主页作品场域内移动指针，观察位置发生小幅变化，主对象维持稳定的构图锚点。近处与远处产生不同程度的相对运动，所有部分遵循同一套相机和深度关系。

- 场域内可有低增益视点响应；进入真实对象区域后再启动更明确的目标对焦。
- 指针停止，视点平顺稳定，允许观察；离开后归位。
- 正文、标题和导航不随相机摇晃。
- 不让盒盖、板卡和线缆作为互不相干的卡片漂浮。
- 不能只把整张图片一起平移、缩放或倾斜。
- 先关闭景深与轨迹，仍然应能感知前后关系变化。

相机幅度受单张图片的有效信息限制。目标是可辨的相对视差，不是大角度展示未知侧面。若画面变成果冻、出现拉丝或元件结构变形，先修复深度与几何。

## 5. M02 — 景深围绕对象的前后关系

基准状态以主要研究对象清楚为先。移动焦点时，前后区域的清晰关系平顺改变；同一深度的区域不应仅因离鼠标远就变模糊。

- 焦点来自当前相机下的有效对象深度，独立于视角跟随控制。
- 指针跨过细线、孔洞和对象边界时，焦点保持稳定，不频繁跳焦。
- 无有效命中时回到主对象默认焦点。
- 不做可见圆窗、光斑、光晕或放大镜。
- 原图已经拍糊的区域无法被网页景深重新变清楚；选取有可辨细节的区域验收，明确这种源素材限制。
- 景深的最大模糊应让项目仍可观察，不能把主体当抽象色块处理。

这是深度代理上的渲染景深，不是对原始相机光学过程的校准复现。

## 6. M03 — 背景轨迹：低对比的介质扰动

本轮选择一个明确方向：薄、轻、有流动惯性的背景扰动。它可以带少量折射或雾状明暗变化，但不遮挡研究对象。

必须出现的形态：

- 慢移：局部、轻微的扰动；快移：沿运动方向拉伸、连续的尾部。
- 转弯：尾部保留少量惯性，发生弯曲与扩散，不只是精确描摹指针路径。
- 停止：已有扰动继续短暂演化，然后恢复干净底色。
- 色相靠近页面基底，以低对比明暗与少量色偏表达；不变成亮绿线、等距点、彩色墨水或大团烟。
- 没有用户输入时保持安静，不要求持续自动播放。
- 场域背景可有极低对比的明暗／纹理，供扰动显现；对完全均匀底色只做坐标位移不会产生可见效果。
- 扰动只作用于背景表现层，不能把板卡、文字、细线和标签扭成液体。

轨迹属于次要响应。移动鼠标时，主对象与标题仍然是第一视觉焦点。具体技术见 WEBGL_SPEC.md；只把旧轨迹改细、改透明不算完成形态升级。

## 7. M04 — 标题局部响应

保留可读的 HTML 标题，通过同字形叠层、局部高亮或显现响应指针。文字骨架稳定，视觉重复层不重复进入辅助技术阅读顺序。

首页标题可同时承担项目标题，不额外堆两个大标题。详情页复用同一机制；真实链接有清楚键盘焦点，无链接标题不伪装成按钮。

## 8. 后处理的艺术边界

后处理服务深度、边缘和颜色一致性。正确景深、输出转换与必要抗锯齿是基础；颗粒、暗角、bloom 和色差不列为必需。

不得用强滤镜掩盖平面几何，不能破坏 PCB 细节、文字和标记颜色。关闭景深／颜色处理时，源图与基准构图仍应成立。

## 9. 参数是调节初值

| 参数 | 初值建议 | 以什么判断 |
| --- | --- | --- |
| 相机角度范围 | 从约水平 ±2°、垂直 ±1.5° 起调 | 实际层间视差与遮挡余量，不追求更大角度 |
| 视角跟随 | 约 160–300 ms 量级 | 灵敏、有稳定感，无机械摆动 |
| 对焦过渡 | 约 220–450 ms 量级 | 跨边界不跳动，不抢过视点 |
| 离开归位 | 约 350–650 ms | 连续回到同一基准 |
| 轨迹主要消退 | 约 0.6–1.4 s | 有惯性且不留长久污迹 |
| 景深上限 | 约 2–6 CSS px 的视觉量级 | 源图细节仍可观察；像素与 shader 参数正确换算 |

这些不是 Lusion 原始参数。素材变化后通过集中配置调整。

## 10. 页面与适配

继续维持主页与一个项目详情页。已有合理内容保留，不生成虚构项目。主页集中展示，详情承载正文、完整照片与有价值的局部图。

使用原生滚动，保留文本选择、链接、浏览器返回与键盘导航。触屏和减少动效模式提供清楚静态构图；不要求用户额外点击才能触发本应直接执行的链接。

静态回退属于必要兼容性。正常桌面下本章 M01–M04 必须按其实际机制完成；回退不算 WebGL 主验收通过。

实施状态、图形调试、深度估计说明与性能数字放入报告或开发检查模式，不放到访客主界面。
