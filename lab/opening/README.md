# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 直接开幕（S）、½ 慢放（D）、隐藏（H）。

**状态：v12，与正式站点（`src/lib/motion/gate.ts`）一致。** 以后的调整仍然先在这里试，确认后再移植。

首屏的样式在构建时直接从 `src/styles/home.css` 取出，所以原型不会和正式站点走样；首屏文字写在 `template.html` 里。

## v12 相对 v11 改了什么

用户看过 v11 后指出：中间的方块放大到全屏那一段生硬。原因有三个——方块的大小用了「慢-快-慢」的曲线，在标志已经减速之后又加速了一次；它是一个孤零零的、边缘笔直的方块在匀速放大；窗里是一张半透明淡入的肖像。v12 的改法：

1. **一口气，然后减速。** 窗的大小不再单独插值，而是「画出来的中心方块 × 一个比例」，比例用减速曲线：直边 0.1–0.75s（outCubic）冲出屏幕，不到半秒已经出画。没有二次加速。
2. **虹膜，不是方块。** 窗带着标志自己的 45° 切角打开：方块 → 八边形 → 近似菱形。直边出画以后，剩下的暗场是四个 45° 的斜角，它们越来越慢地（0.28–1.3s，outSine）退到角上——正好是色块落位的位置，色块在这时被窗沿扫成深蓝。
3. **有厚度。** 暗场像一张略高于纸面的幕：窗沿内侧有一圈很淡的投影（`shade`，半分辨率 canvas，八条渐变带）。
4. **窗里是字。** 首屏换成排字封面，FIELD / NOTES 的字母在窗里逐个升起，不再有肖像淡入。

v11 带来的其余部分保留：双层标志（窗外纸白、窗内深蓝）、随蓄力回吸再抛出的微尘、蓄力时的钴蓝光与蓄满的轻颤、等待时朝指针倾斜、首屏 1.05 倍的纵深。

另修复：落位后量标志宽度量到了已隐藏的暗场层（得 0），四角色块会消失；现在量页面层。

没有用到的东西（都在排除清单里）：顶栏、入口卡片、滚动字幕带、描框 / 圆环提示、先转后开、凌乱走向的线条、分形、逆放。

## 流程与参数（v12）

1. **绽放**（约 2.4 秒）：每一块从标志中心点放大到位，中心方块带回弹，随后两对角件，最后两片红刃。
2. **蓄力**：按住（或空格 / 回车）缩小 14%、反向转 28°，约 0.42 秒蓄满；松开即弹开。快速单击至少蓄到 60%。滚轮、上滑、↓ 自动做 0.2 秒短蓄力。
3. **开幕**（约 1.8 秒，弹簧）：
   - 旋转、弹回原大、放大、落位：`SPRING`、`T.spin` / `T.zoom` / `T.settle`，与 v10 相同。
   - 纸窗直边：`T.win`（0.1–0.75s）。终点 `sideEnd` = 长边的一半 + 短边的 0.3。
   - 纸窗斜角：`T.reach`（0.28–1.3s）。终点 `reachEnd` = 1.1 ×（宽 + 高）/ 2，约 1.05 秒盖住全屏，随后暗场层隐藏。
   - 方块由纸白过渡到纸色：`T.veil`（0.04–0.3s）。
   - 首屏内容从 `T.home`（0.3s）起浮现；纵深 `DOLLY`（1.05）在 `T.dolly`（0.1–1.6s）内归一。
   - 投影：`opening()` 里的 `shade`（0.06–0.3s 出现，0.9–1.2s 消失），深浅在 `shade()` 的 `.3`。
   - 微尘：`opening()` 里的 `vz`（抛出速度）与 `dust`（0.45–1.05s 淡出）；蓄力回吸在 `charge()` 的 `vz`。
   - 光：`.night::before` 的 `--glow`，蓄力时由 `charge()` 推到 1。

实现要点：`.night`（暗场、微尘、纸白碎片）叠在 `.day`（深蓝碎片、投影，透明底）之上；窗是 `.night` 上一个随标志旋转的八边形 `clip-path` 洞（`polygon(evenodd, …)`），每帧由 `apply()` 更新。

自动检查用的钩子（仅原型）：`__lab.intro(t)` / `idle()` / `charge(v)` / `open(t)` 定格某一时刻；`__lab.manual(true)` 后用 `__lab.step(dt)` 逐帧推进、`press()` / `release()` 模拟按住松开、`lean(x, y)` 设定倾斜。

## 旧版本

- `template-v11.html`：方形纸窗、旧首屏（油画 + 字标）的版本（`node lab/opening/build.mjs template-v11.html`）。
- `template-v10.html`：暗场整体淡出的版本（`node lab/opening/build.mjs template-v10.html`）。
- `template-v4.html`：更早的同心环版本（`node lab/opening/build.mjs template-v4.html`）。

弹簧的软硬在 `SPRING`（[阻尼, 频率]：阻尼越小越弹，频率越高抖得越快）。旋转角度 `SPIN` 必须是 180 的倍数；落位位置在 `FINAL` / `FINAL_NARROW`（参数含义同正式站点 gate.ts）。
