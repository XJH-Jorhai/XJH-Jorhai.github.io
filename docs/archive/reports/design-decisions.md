# 本轮视觉与实现选择

日期：2026-10-25。项目名称采用用户提供目录中的毕业设计名称；站名暂用“项目与记录”。

视觉核心是实物照片中绿色板面、黑色外壳、金色接口及红黑线缆之间的关系。实拍保留了装配环境、打开的前盖和接口，使用 `preserve-scene`，以完整摄影平面呈现，不强行分离复杂线缆。所有公开素材由本地 Sharp 确定性输出，没有生成式改图。

底色采用与深色泡棉、机壳协调的石墨绿，文字为暖白，唯一主强调取自板面与指示灯的黄绿色关系并降低饱和度。准确色值仅存在图片配方，脚本输出清单，HTML直接输出初始颜色角色，CSS与Canvas消费同一来源。使用系统无衬线字体，无外部字体请求。

桌面以大标题、左侧短说明和右侧宽幅实物图构成不对称版面，不重复展示第二张首页主图。手机重新排为标题、全幅图、短说明与入口；保留整张图，是为了不截断左右线缆和接口。详情图更宽，正文收窄至650px，使用三个小节与局部、独立板图完成从展示到阅读的过渡。

封面使用同一画幅的清晰图、预生成柔焦图和软边清晰蒙版，承载层轻微平移；这是屏幕空间聚焦模拟，不是光学深度或三维重建。Motion统一调度指针响应和有限状态过渡；Canvas仅在首页作品场域产生短寿命连续痕迹。选择CSS图层路线，无Three.js、WebGL或模型下载。

项目方法、性能指标、实验结果、正式作者信息未确认，不从照片猜测。文案集中于 `src/content/projects/project-01.md` 与 `src/config/site.ts`，明确标注“文字待补”。论文保留在用户原目录，不复制到公开站点。

依赖：Astro用于静态路由、内容集合和Markdown；Motion用于统一动画调度与状态过渡；Sharp用于本地图片派生；TypeScript与@astrojs/check用于类型和模板检查；Playwright仅用于开发期真实浏览器验证。版本以package-lock.json及RUNBOOK为准。参考已核查的官方[内容集合文档](https://docs.astro.build/en/guides/content-collections/)与[Motion frame文档](https://motion.dev/docs/frame)，以实际安装包类型和构建结果验证API兼容。
