# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程（v3）

1. **A 不规则法阵**（滚动驱动，约 900px 滚动量到 100%）：红色只在中心，核心从水平的「红 ▪ 白 ▪ 红」随进度扭成斜刃。外面是一圈圈白色臂，越往外越粗（接近标志本身的重量）。用固定随机种子打乱每圈的间距、朝向、每条臂的最终长度（50–100%）和开始伸长的时机，外圈偶尔缺一条臂；各圈还会缓慢自转。所有臂一开始就在，只是很短。进度 30 / 60 / 90% 时每圈各转一个不同的角度（35–130°，方向随机），从内向外依次转。只有最内圈对齐成标志。停手会慢慢退回；点击或回车自动补满。
2. **B 开幕**（自动，约 3.9 秒，不逆放）：最内圈落定为精确标志（0–0.3s）→ 镜头拉远 6 倍，法阵缩成漩涡并继续自转（0.15–2.4s）→ 一道 45° 斜边从左侧扫过，线条先染上首页的颜色（1.45–3.0s，inOutQuart）→ 第二道斜边跟着把缝隙填成首页画面（2.05–3.6s）→ 淡出到首页首屏。

种子、圈距、线宽在 `buildRings()`；时间点在 `TB`、`CLICKS`；拉远倍数 `ZOOM`；斜边形状在 `sweep()`。
