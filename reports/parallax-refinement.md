# 清晰视差与轮廓修订

2026-10-25，按用户最新反馈实施。此记录取代v2关于必须启用景深和对焦切换的验收要求；原v2报告保留为历史。

## 修改

- 从运行代码移除景深采样、焦距状态、raycast对焦和焦点平滑；后处理保留颜色输出、FXAA与仅诊断用的场景深度显示。不是仅将模糊半径设小。
- 沿留存的4032×2090原图重新细描插头台阶、弯曲线缆下缘、外壳和三枚金属接口。旧轮廓的长直线曾穿过橙色线缆，产生用户截图中的切边／重复边；已校准到可见像素边界。
- 底层背景按同一轮廓剔除硬件，并留约4px排除余量；使用邻近真实背景的局部镜像延展，替代整块缩放纹理和单像素拉伸。没有补画电路、线缆、接口或文字。
- 保留相机轨道、三层前后关系、原始内容／路由与背景流场。相机幅度仍为水平±2°、垂直±1.5°，没有靠关闭视差掩盖边界。

## 验证

实际执行 images、check、build。新版 npm run test:webgl / test:browser 指向 scripts/verify-parallax-refinement.mjs，默认访问当前4321预览，也接受PREVIEW_URL。

真实Edge浏览器检查详情图左／中／右、左上与右下极限，并复查主页。固定相机，将鼠标从板卡移到前盖，截取主图PNG逐字节一致：不再发生对焦或清晰度切换。运行快照不含DOF pass和focus状态。与单平面对照，1180px详情图中前盖仍有约11.4 CSS px的额外左右视差。浏览器未记录pageerror。

证据：`evidence/parallax-refined/results.json`、`cable-comparison.jpg`、各视角PNG与两页最终截图。旧视差/景深证据不代表当前默认行为。

照片已有的拍摄虚焦会保留，没有生成式锐化。分层仍是单图视觉代理，背景延展只服务有限视角；不支持绕到未拍摄的背面。旧版提到的真实系统隐藏暂停未验证状态没有因本次轮廓修改自动转为通过。
