# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程

1. **A 铺满**（滚动驱动，约 900px 滚动量到 100%）：中心只有红刃和白色方块 → 四个白臂同时长出 → 复制体从中心一圈圈铺满屏幕。进度 30 / 60 / 90% 时所有方块各转 90°，从中心向外波浪传开（像密码锁）。停手会慢慢退回；点击或回车自动补满。
2. **B 开幕**（自动，约 6 秒）：逆向播放回到中心核心（0–1s）→ 核心放大、白臂重新长出（1–2s）→ 每个标志一分为四，越分越小（6 层，约 2–4s）→ 最小的块从中心向外染上首页的颜色（3.7–5s）→ 缝隙被填满，变成首页首屏（4.4–5.5s）。
3. **落地**：首页首屏。鼠标附近的画面会重新「解体」成 TEISU 小方块，像一面放大镜。

时间点都在 `template.html` 的 `timeline()`、`drawTiling()` 和常量 `CLICKS`、`SPLIT` 里。
