# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 直接开幕（S）、½ 慢放（D）、隐藏（H）。

**状态：v11 是待确认的原型，正式站点（`src/lib/motion/gate.ts`）仍是 v10。** 用户确认后再移植。

## v11 相对 v10 改了什么

三段流程（绽放 → 蓄力 → 边转边弹开）、弹簧、时长（约 1.8 秒）和最终落位都没有变。变的是「暗场怎么离开」和舞台的反应：

1. **暗场是被切开的，不是淡出的。** 标志中心的方块本来就是纸白色——它就是首页的纸。松手后它不再缩小消失，而是变成一扇纸窗，跟着标志边转边长大，直到吞没整个屏幕；窗里是已经在那里的首屏（油画、字标）。v10 在 0.4–0.95 秒之间几乎是空的暗场加一次整体淡出，这段现在是全片最满的画面。
2. **变色就是窗沿扫过。** 同一枚标志有两层：暗场层（纸白碎片）在上，页面层（深蓝碎片）在下。窗沿之外看到的是暗场和纸白，之内是纸和深蓝。所以碎片仍然是「快落地时才由纸白变深蓝」，而且纸白碎片永远不会落在纸色上——只是现在变色有了方向和边界。红刃两层同色。
3. **微尘听标志的。** 按住蓄力时微尘被吸回深处；松手时被抛向镜头，并随标志一起转。速度快的微尘画成它这一帧走过的短迹，全部沿同一股径向流动（不是乱线）。绽放开始时微尘也有一次从深处涌出。
4. **蓄力有光。** 标志背后一团钴蓝的光随蓄力聚拢变亮，松手后 0.5 秒内散去；蓄满时标志有极轻微的颤动（约 ±0.5°）。
5. **等待时会看人。** 精细指针下，标志作为一个刚性平面朝指针方向倾斜（最多约 7° / 9°），形状不变；蓄力到可以松手之前已经回正，所以开幕始终是正面。
6. **首屏有一点纵深。** 窗打开的同时，首屏从 1.05 倍缓缓退回原大。

没有用到的东西（都在排除清单里）：顶栏、入口卡片、滚动字幕带、描框 / 圆环提示、先转后开、凌乱走向的线条、分形、逆放。

## 流程与参数（v11）

1. **绽放**（约 2.4 秒）：同 v10。每一块从标志中心点放大到位，中心方块带回弹，随后两对角件，最后两片红刃。
2. **蓄力**：按住（或空格 / 回车）缩小 14%、反向转 28°，约 0.42 秒蓄满；松开即弹开。快速单击至少蓄到 60%。滚轮、上滑、↓ 自动做 0.2 秒短蓄力。
3. **开幕**（约 1.8 秒，弹簧）：
   - 旋转、弹回原大、放大、落位：同 v10（`SPRING`、`T.spin` / `T.zoom` / `T.settle`）。
   - 纸窗：`T.win`（0.3–1.4s，inOutCubic）从中心方块的实际大小长到屏幕对角线的 0.56 倍（任何角度都盖住全屏）；盖住后暗场层直接隐藏。
   - 方块由纸白过渡到纸色：`T.veil`（0.04–0.3s）。
   - 首屏内容从 `T.home`（0.34s）起浮现；纵深 `DOLLY`（1.05）在 `T.dolly`（0.1–1.6s）内归一。
   - 微尘：`opening()` 里的 `vz`（抛出速度）与 `dust`（0.45–1.05s 淡出）；蓄力回吸在 `charge()` 的 `vz`。
   - 光：`.night::before` 的 `--glow`，蓄力时由 `charge()` 推到 1。

实现要点：`.night`（暗场、微尘、纸白碎片）叠在 `.day`（深蓝碎片，透明底）之上；窗是 `.night` 上一个随标志旋转的方形 `clip-path` 洞（`polygon(evenodd, …)`），每帧由 `apply()` 更新。

自动检查用的钩子（仅原型）：`__lab.intro(t)` / `idle()` / `charge(v)` / `open(t)` 定格某一时刻；`__lab.manual(true)` 后用 `__lab.step(dt)` 逐帧推进、`press()` / `release()` 模拟按住松开、`lean(x, y)` 设定倾斜。

## 旧版本

- `template-v10.html`：正式站点目前的版本（`node lab/opening/build.mjs template-v10.html`）。
- `template-v4.html`：更早的同心环版本（`node lab/opening/build.mjs template-v4.html`）。

弹簧的软硬在 `SPRING`（[阻尼, 频率]：阻尼越小越弹，频率越高抖得越快）。旋转角度 `SPIN` 必须是 180 的倍数；落位位置在 `FINAL` / `FINAL_NARROW`（参数含义同正式站点 gate.ts）。
