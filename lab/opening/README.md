# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程（v2）

1. **A 锁 / 法阵**（滚动驱动，约 900px 滚动量到 100%）：红色只在中心——核心一开始是水平的「红 ▪ 白 ▪ 红」，随进度扭成标志的斜刃。外面是一圈套一圈的白色臂（第一圈就是标志自己的臂，外圈是放大的线框）。所有臂一开始就在，只是很短，长度随进度同步伸长。每圈起始朝向不同，进度 30 / 60 / 90% 时像密码锁的转盘一样转动；90% 时全部对齐。停手会慢慢退回；点击或回车自动补满。
2. **B 开幕**（自动，约 5.4 秒）：对齐后停一拍，标志轻轻呼吸（0–0.55s）→ 逆放：所有臂缩回，核心变回水平（0.55–1.45s）→ 白臂重新长出（1.45–2.25s），同时画面持续拉远，标志变成一格，复制体从中心向外复制、越来越小，最小格 40px（手机 28px）（1.85–3.9s）→ 线条从中心向外染上首页的颜色（3.25–4.45s）→ 每格从中心向外填满（3.75–4.95s）→ 淡出到首页首屏。

时间点都在 `template.html` 的 `TB`、`CLICKS`、`buildRings()` 和 `drawField()` 里。
