# 开幕原型（本地）

只包含开幕动画和首页首屏，用来快速迭代，不影响正式站点。

```sh
npm run lab
```

生成 `lab/opening/teisu-opening.html`（单文件，图片内嵌），双击即可在浏览器打开，不需要服务器。
改动画只改 `template.html`，再运行一次 `npm run lab`。生成的 HTML 不提交。

左下角调试条（仅原型）：↺ 重播（R）、⇥ 跳到开幕（S）、⤓ 直接落地（L）、隐藏（H）。

## 流程（v6，以「落位色块」版为基础）

1. **绽放**（约 2.4 秒）：暗场，微尘飘向镜头。标志从中心长出：每一块都从标志中心点放大到位（中心方块带回弹，随后两对角件成对，最后两片红刃），整枚标志从屏幕深处轻轻前移。暗场中深蓝部分显示为纸白。
2. **描框**（滚动驱动）：粗白方框（无底轨）从左上、右下两角同时描出，约 900px 滚动量描满；红刃随进度沿斜线微微松开、中心方块微缩。停手会慢慢退回；点击或回车自动补满。
3. **开幕**（约 2.25 秒）：**边转边开**——标志在整个开幕过程中转 180°（0.05–2.2s，inOutCubic，转速在放大时最快，落位时一起减速停下）；同时由纸白变回深蓝（0.05–0.7s）并放大（0.25–1.25s），碎片以 outQuint 缓停落到四角（0.7–2.2s）：左上、右下深蓝块，右上、左下红刃尖角。暗场淡出（0.75–1.55s），首页内容从 1.15s 起在色块之间浮现。色块留在首页首屏，随页面滚走。

首屏：纸色底，左边装框的油画，右边 TEISU 字标、一句话、小字，没有入口卡片。

时间点在 `T`、`BLOOM`、`INTRO_END`；旋转角度 `SPIN`（必须是 180 的倍数）；落位位置在 `FINAL` / `FINAL_NARROW`（参数含义同正式站点 gate.ts）。旧的 v4 原型保留在 `template-v4.html`（`node lab/opening/build.mjs template-v4.html`）。
